# Перспективные конфигурации моделей

## Назначение

Модель, не прошедшая текущий отбор, не обязательно бесполезна. Причиной может
быть нехватка видеопамяти, неудачный шаблон вызова инструментов, несовместимость
с текущей версией Ollama или слишком большой контекст.

Текущий строгий фильтр стенда `win11-local-rx6800`: Claude Code CLI работает
через Ollama на localhost, модель должна помещаться в видеопамять Radeon RX
6800 целиком, а агент должен действительно выполнять инструменты, а не
изображать их вызовы текстом.

## Стенд с большей видеопамятью

| Модель | Что произошло на RX 6800 | Перспективная конфигурация |
|---|---|---|
| `ministral-3:14b-ctx32k` | `12%/88% CPU/GPU`, на GPU загружено `40/41` слоев | Проверить на видеокарте от 24 ГБ. До этого допустим короткий перебор контекста: `24576`, `16384`, `8192`. |
| `qwen3-coder:latest` | Базовый образ: `67%/33% CPU/GPU`; профиль `ctx32k`: `32%/68% CPU/GPU` | Вернуть в тесты на стенде от 24 ГБ, предпочтительно от 32 ГБ для задач с длинным кодом. |
| `qwen3.6:latest` | Базовый образ: `58%/42% CPU/GPU`; профиль `ctx32k`: `47%/53% CPU/GPU` | Проверить на стенде от 32 ГБ. |
| `gemma4:26b` | Базовый образ: `44%/56% CPU/GPU`; профиль `ctx32k`: `29%/71% CPU/GPU` | Проверить на стенде от 24 ГБ, затем сравнить качество восстановления кода. |
| `qwen2.5-coder:14b` | `18%/82% CPU/GPU`; одновременно имитировала вызовы инструментов текстом | Возвращать только при наличии большей видеопамяти и после проверки нового шаблона инструментов. |

Ее полезно проверять при изменении шаблонов.

## Новые запасные кандидаты

Эти модели еще не считаются проверенными. Они компактны либо интересны как
отдельная точка сравнения.

| Модель | Для чего проверить |
|---|---|
| `ministral-3:3b-ctx32k` | Локальный профиль создан из `ministral-3:3b`. Проверить как быстрого помощника для разметки и объяснения небольших функций. |
| `granite4.1:3b-ctx32k` | Локальный профиль создан из `granite4.1:3b`. Проверить как компактную контрольную модель для пакетной обработки. |
| `phi4-mini:3.8b-ctx32k` | Локальный профиль создан из `phi4-mini:3.8b`. Проверить заявленную поддержку инструментов. |
| `llama3-groq-tool-use:8b` | Отдельная проверка дисциплины вызова инструментов при небольшом контексте. |
| `deepseek-coder-v2:16b` | Статический анализ кода на будущем стенде с большей видеопамятью. |
| `granite-code:8b` | Дополнительная модель для анализа кода без требования быть основным агентом. |

Воспроизводимые описания первых трех профилей находятся в
`tools/modelfiles/`. Создать их повторно можно командами:

```powershell
ollama create ministral-3:3b-ctx32k -f tools\modelfiles\ministral-3-3b-ctx32k.Modelfile
ollama create granite4.1:3b-ctx32k -f tools\modelfiles\granite4.1-3b-ctx32k.Modelfile
ollama create phi4-mini:3.8b-ctx32k -f tools\modelfiles\phi4-mini-3.8b-ctx32k.Modelfile
```

краткие выводы в `docs/runbooks/runs/`, оставляя сырые данные на тестовом
стенде.
